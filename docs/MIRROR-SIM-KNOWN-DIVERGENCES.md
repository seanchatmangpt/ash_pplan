Standing: PARTIAL

Register of public `lib/ash_pplan` surfaces the mirror-sim server does not (yet) mirror over
the wire. The coverage compiler (`test/support/mirror_sim/coverage.ex`) reads every row that
starts with `| KD-`. A row registers only if all four cells are non-empty; otherwise the
surface stays MISSING and `scripts/mirror_sim/coverage.exs` exits 1.

Inventory scope: modules compiled from the repo `lib/` dir only; `@doc false` functions,
`exception/0,1`, `__*__` and generated functions are excluded. On Ash/Spark modules only
explicitly documented functions count. A mirror `name/N` covers `name/M` for `M <= N`.
A phantom is a mirror surface not exported (`function_exported?/3`) by an `AshPPlan.*` module.

Surface cell forms: `Mod.fun/arity`, `Mod.*` (whole module), comma-separated.
